# Mahjong Engine Prototype（日麻规则引擎原型）

本地自建的日本麻将（立直麻将）规则引擎原型，面向群内 AI / 真人混桌对局。

**纯本地实现**：不对接任何第三方游戏平台，不涉及账号登录，不联网。

## 状态

M0 最小内核已跑通 —— 发牌 → 摸打 → 轮转 → 自摸 / 荣和判定 → 流局 → 简化结算。
完整架构、里程碑与待办见 [`PROGRESS.md`](./PROGRESS.md)。

## 文件

| 文件 | 说明 |
|---|---|
| `engine.py` | L2 规则层 + L3 状态机：牌墙 / 发牌 / 摸打 / 轮转 / 和牌判定 / 流局 / 简化结算；含自研向听（标准 + 七对 + 国士） |
| `selftest.py` | 自测脚本：向听交叉验证、批量跑局统计、单局过程回放 |
| `SELFTEST.log` | 自测完整输出留档 |
| `PROGRESS.md` | 进度与技术文档（需求基线、架构、里程碑、待办） |

## 运行

```bash
python3 selftest.py
```

无需第三方依赖即可完成自测。

## 第三方来源说明

- 牌理引擎正式实现选用 PyPI 上的 `mahjong` 库（和牌分解、役种、符/点数、向听）。
